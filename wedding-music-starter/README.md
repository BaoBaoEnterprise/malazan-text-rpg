# Wedding Music 🎶

Planning space for our wedding reception music. Everything lives in a few
markdown files — open one, edit it, save. That's the whole system.

## The files

| File | What goes in it |
|------|-----------------|
| [must-play.md](must-play.md) | Songs that absolutely need to happen |
| [do-not-play.md](do-not-play.md) | The banned list |
| [special-moments.md](special-moments.md) | First dance, entrances, cake cutting, last song |

New here? Read **[CONTRIBUTING.md](CONTRIBUTING.md)** first — it explains how
we both edit these files without stepping on each other's changes. No git
experience needed.
